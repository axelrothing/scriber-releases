# Support

Report installation failures or reproducible Stable issues through [this repository's issues](https://github.com/axelrothing/scriber-releases/issues). Include your Windows version, Scriber version, installation type, steps to reproduce, and the error message. Remove personal information from diagnostic excerpts.

Do not post API keys, tokens, cloud credentials, private libraries, or full databases in a public report. For sensitive reports, contact the publisher through the contact information on [their GitHub profile](https://github.com/axelrothing).

Check the installation and recovery guide before restoring data. Keep backups until a new installation and any separately approved cloud migration have been verified on your devices.
