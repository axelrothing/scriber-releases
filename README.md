# Scriber

Scriber is a local-first Windows writing and vocabulary app. Correct or rewrite selected text, keep a bilingual English/Norwegian vocabulary library, and review saved words.

Download the **Scriber 1.0.0 Stable Setup** from [Releases](https://github.com/axelrothing/scriber-releases/releases). Windows 11 x64 and Microsoft Edge WebView2 Evergreen Runtime are required. Windows on ARM and other platforms are not release targets.

Writing assistance requires your own OpenAI API key. OpenAI usage is billed to your account; an API account and credits are separate from a ChatGPT subscription. Vocabulary storage and review work locally. Cloud sync is optional.
